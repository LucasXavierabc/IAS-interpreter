# IAS Interpreter
 
Simulador em Python do processador IAS (Institute for Advanced Study), uma das arquiteturas computacionais mais importantes da história da computação e precursora do modelo de programa armazenado utilizado pelos computadores modernos.
 
## 📖 Sobre o Projeto
 
O processador IAS foi desenvolvido no Institute for Advanced Study (IAS), em Princeton, sob a liderança de John von Neumann entre 1942 e 1951. Sua arquitetura serviu como base para o desenvolvimento dos computadores modernos, introduzindo o conceito de armazenar instruções e dados na mesma memória.
 
Este projeto implementa uma simulação da máquina IAS em Python, permitindo a execução de programas escritos no formato utilizado pela arquitetura.
 
O simulador interpreta instruções, gerencia memória e reproduz o comportamento básico do processador IAS para fins educacionais e de estudo da Arquitetura de Computadores.
 
---
 
## 🚀 Funcionalidades
 
- Simulação do conjunto de instruções da máquina IAS
- Execução de programas no formato `.IAS`
- Gerenciamento da memória simulada
- Interpretação do ciclo de busca, decodificação e execução de instruções
- Projeto voltado para fins acadêmicos e educacionais

## ⚙️ Como Executar
 
### Pré-requisitos
 
- Python 3 instalado
 
### Execução
 
Abra um terminal na pasta do projeto e execute:
 
```bash
python3 ias3.py arquivo.IAS
```
 
Substitua `arquivo.IAS` pelo programa que deseja executar.
 
Exemplo:
 
```bash
python3 ias3.py programa1.IAS
```
